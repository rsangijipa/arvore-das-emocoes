# Audio Assets

The sound engine is wired with `howler` and expects these files in `public/audio`:

- `ambient-loop.mp3` (continuous ambient bed)
- `leaf-hover.mp3` (very subtle chime)
- `quote-random.mp3` (page + leaves gesture)
- `favorite-soft.mp3` (warm short confirmation)

If files are missing, the app continues to work silently.
